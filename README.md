## Featured Project

### KibreSec — AI Security & Red Teaming Platform

**Status:** Proposal and Architecture Stage

KibreSec is my final-year Computer Science project, proposed as an automated AI red-teaming platform for testing the security of LLM-powered applications.

The platform aims to help developers identify potential security weaknesses in their AI applications through automated security testing.

**Initial Security Testing Categories:**
- Prompt Injection
- Jailbreak Attacks
- Controlled Sensitive-Information Disclosure

**Planned Technology Stack:**

| Component | Technology |
|---|---|
| Frontend | React.js, Vite |
| Backend | Node.js, Express.js |
| Database | MySQL |
| Testing Engine | Custom JavaScript-based Evaluation Engine |

The project focuses on helping developers discover potential weaknesses, examine test evidence, and understand possible security improvements.
